This folder contains start and stop scripts for Windows and macOS/Linux.

- `start.cmd`: start container on Windows (default, no PowerShell execution-policy dependency)
- `stop.cmd`: stop container on Windows (default, no PowerShell execution-policy dependency)
- `start.ps1`: PowerShell start script for Windows
- `stop.ps1`: PowerShell stop script for Windows
- `start.sh`: start container on macOS/Linux
- `stop.sh`: stop container on macOS/Linux
